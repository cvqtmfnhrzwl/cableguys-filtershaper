## Overview

Cableguys FilterShaper applies LFO-modulated filter sweeps using a drawable shape editor, enabling complex rhythmic and melodic filter motion synchronized to your DAW.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Cableguys FilterShaper** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Drawable Modulation** | Draw any modulation curve and assign it to filter cutoff |
| **Multiband** | Split signal into bands and apply independent filter motion per band |
| **Tempo Sync** | Lock filter modulation to BPM for rhythmic sweep patterns |
| **Oversampling** | Up to 4x oversampling for clean filter resonance at high gains |
